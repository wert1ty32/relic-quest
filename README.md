# Relic Quest · Таємниці артефактів

3D-гра в браузері про молодого дослідника: розкопуй реліквії, досліджуй їх у лабораторії, виставляй артефакти в музеї й заробляй на відвідувачах, що приїжджають автобусом. А потім спускайся в стародавні данжі разом із квадратною лисичкою-дослідницею.

Стиль — брендбук Tourism Department (НУ «Львівська політехніка»): кремовий, лісовий зелений, помаранчевий акцент, шрифти Unbounded / Manrope / Caveat.

## Запуск
Це статичний сайт: один файл `index.html`, three.js r128 підвантажується з cdnjs.

```bash
python3 -m http.server 8000
```
Відкрий http://localhost:8000. На Vercel — імпортуй репозиторій без збірки (Framework: Other, Output: корінь).

## Керування
WASD — рух · Shift — біг · миша (затисни й тягни) — камера · R — Shift Lock · Пробіл — стрибок · E — дія (затисни) · F — ліхтарик · Q — аптечка · H — дім · M — карта · B — магазин · I — інвентар · C — колекція · U — покращення. На телефоні — джойстик і кнопки на екрані.

## Що в грі
- Рельєф, панорама гір 360°, трава й кущі з вітром, метелики й птахи.
- Музей-павільйон, лабораторія з 3 дослідницькими столами (дослідження — 2 хвилини).
- Автобусна зупинка: відвідувачі приходять, оглядають вітрини й платять за перегляд.
- Крамниця «Компас»: ліхтарик, компас, металошукач, детектор скарбів, аптечка, мотузка, відмички, декодер печаток.
- Данжі: Піщаний каньйон, Затоплений храм, Темна гробниця, Руїни обсерваторії.
- Запечатані скрині трьох рівнів із багатоетапними логічними замками.
- Детальна карта з позначками, кнопка «Дім», збереження в браузері.

## Структура
```
src/00-head.html   стилі та розмітка інтерфейсу
src/10-data.js     артефакти, предмети, скрині, загадки, баланс
src/20-engine.js   рендер, рельєф, гори, текстури, моделі
src/30-world.js    карта світу, будівлі, данжі, рослинність
src/40-logic.js    економіка, відвідувачі, дослідження, загадки
src/50-player.js   рух, камера, Shift Lock, взаємодії
src/60-ui.js       звуки, HUD, карта, вікна
src/70-main.js     керування, головний цикл, завантаження
build.py           збирає все в index.html
```
Після змін у `src/` виконай `python3 build.py`.
